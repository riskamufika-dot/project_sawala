RIS & BAR — Official Coffee Shop Web Application

project ini dibuat untuk memenuhi Test Internship di Salawa Tech.

Aplikasi web Single Page Application berbasis client-side untuk RIS & BAR Coffee Shop yang dirancang dengan nuansa cozy, minimalis, dan estetik (creamy-brown style). Aplikasi ini mendemonstrasikan pengelolaan data menu, pencarian dinamis, keranjang belanja, serta manajemen halaman interaktif tanpa perlu memuat ulang browser.

Fitur Utama
1. Sistem Navigasi Dinamis: Perpindahan halaman (Home, Menu, About) yang mulus menggunakan kontrol state dari Alpine.js.
2. Pencarian & Filter Menu Instan: Fitur pencarian rasa kopi secara real-time disertai filter kategori (All, Coffee Base, Non-Coffee, Pastries).
3. Manajemen Keranjang (Cart System): Pengguna dapat menambah, mengurangi jumlah item, hingga simulasi pemesanan secara interaktif.
4. Halaman About Us Estetik: Tata letak informasi kedai yang komprehensif, mencakup kisah latar belakang, visi-misi, pilar kualitas, hingga info operasional kedai.
5. Desain Responsif: Antarmuka yang adaptif berkat optimasi utilitas Tailwind CSS, nyaman diakses baik melalui perangkat seluler maupun desktop.

Teknologi
1. HTML5: Struktur semantik dokumen web
2. Tailwind CSS: Framework CSS utility-first untuk pembuatan desain estetik dan responsif
3. Alpine.js: Framework JavaScript minimalis untuk mengatur logika aplikasi, state keranjang, dan navigasi halaman
4. Font Awesome: Library ikon grafis untuk mempercantik tombol navigasi dan interaksi
